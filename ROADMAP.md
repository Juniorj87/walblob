# WalBlob Roadmap

Our goal is to build the world's most intuitive and secure decentralized storage interface.

## Q3 2026: Foundation & V2 (Current)
- [x] **Redesign V2**: Complete UI overhaul with premium SaaS aesthetic.
- [x] **Zero-Knowledge Pipeline**: Client-side AES-GCM encryption.
- [x] **Walrus Integration**: Direct upload to decentralized nodes.
- [x] **Mobile Optimization**: Fully responsive layout.

## Q4 2026: Expansion
- [ ] **Multi-file Upload**: Batch processing with progress tracking.
- [ ] **Folder Structure Support**: Virtual folders for organized storage.
- [ ] **Encryption Key Manager**: Local browser storage for managing your keys.
- [ ] **Aggregator Explorer**: Built-in retrieval interface to preview files.

## 2027: Ecosystem
- [ ] **WalBlob API**: Allowing other apps to use our encryption/upload pipeline.
- [ ] **Mobile App**: Native iOS and Android clients using React Native.
- [ ] **Team Sharing**: Shared encryption pools for collaborative work.
- [ ] **Storage Subscription**: Fiat-to-SUI onramp for permanent storage.
